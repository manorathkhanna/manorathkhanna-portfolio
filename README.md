# Manorath Khanna — Portfolio

A responsive, static portfolio site built with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository named `manorathkhanna-portfolio` under the GitHub account `manorathkhanna`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The site will be available at `https://manorathkhanna.github.io/manorathkhanna-portfolio/` after GitHub Pages finishes publishing.
